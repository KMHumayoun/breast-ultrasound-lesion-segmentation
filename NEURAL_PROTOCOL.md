# Prospective neural-stage protocol

Written before the first neural test evaluation. The initial classical baseline was already inspected; this is not an externally preregistered study.

Use the unchanged BrEaST 153/51/52 patient split and 128×128 preprocessing from the classical study. Three fitting seeds; nested 10%/30%/100% annotated training-patient subsets, identical across methods for each seed. Validation is fully annotated for all budgets. No test result may select architecture, epoch, threshold or hyperparameter.

Methods: a compact U-Net variant trained from scratch; the same U-Net without augmentation; DeepLabV3-MobileNetV3 initialized randomly; the official COCO/VOC-pretrained DeepLab with frozen backbone; the same pretrained model fine-tuned throughout. Binary output heads replace the original segmentation classifier. The small-batch DeepLab running BatchNorm statistics remain fixed. This compares standard reference designs and does not propose a novel network.

Training: AdamW, weight decay 1e-4, BCE-plus-soft-Dice loss, batch size four. Fixed learning rates 1e-3 for U-Net and 1e-4 for DeepLab variants. At most 60 epochs, no early stopping before epoch 20, patience ten on lesion-positive validation Dice at threshold .5. Select the best checkpoint by that validation measure. Select one global threshold per fitted model from .2/.35/.5/.65/.8 using validation Dice only. Transform image/mask together for a horizontal flip; image-only gamma .85–1.15 and multiplicative Gaussian speckle sigma .035. Deterministic per-patient/epoch augmentation schedules pair augmented methods. Compute is measured, not asserted equal across architectures.

Primary endpoint: lesion-positive test patient Dice, averaging each patient over three fits before a patient bootstrap. Secondary: spacing-aware HD95/area errors, counted empty-output failures, normal-case false foreground, model parameters, measured training cost and warm synchronized batch-one inference. Record all per-patient outcomes and epoch histories. Sampled MPS live/driver allocations are not a peak-memory guarantee. No clinical validation, hospital transfer or external cohort result is assumed.

Pretraining provenance: [official torchvision model documentation](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.segmentation.deeplabv3_mobilenet_v3_large.html), COCO subset with Pascal VOC categories; the documented weights are about 42.3 MB. Preserve the actual downloaded hash. Input grayscale is repeated to three channels and ImageNet mean/std normalized; 128px task training deliberately differs from the original 520px inference recipe. Third-party pretrained weights are downloaded into ignored data/ and are not redistributed by this repository. Check their upstream terms before sharing derivatives.

References: Ronneberger et al., [U-Net](https://arxiv.org/abs/1505.04597); Chen et al., [Rethinking Atrous Convolution for Semantic Image Segmentation](https://arxiv.org/abs/1706.05587); PyTorch/torchvision implementations and licenses. The compact U-Net changes capacity, normalization and upsampling from the original paper; it is a reference variant, not a faithful reproduction claim.
